# The Funniest Honest Appliance Error

make.fun entry for
`u-xvader-the-funniest-honest-appliance-error-adec4450`.

A dishwasher, in its own flat machine voice, finally admits what it has
been hiding: a fork stuck in its filter since March — and why it stayed
quiet. The humour comes from the fault itself, not a bolted-on pun:
the machine kept a secret because its owner never cleans it either.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

It writes one line (135 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
Stdlib only, no network, no writes inside the repo.
